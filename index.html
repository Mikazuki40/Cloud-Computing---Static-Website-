PURPOSE OF THE WEBSITE

The Abnormality Archive is a static website created as an educational demonstration of HTML, CSS, JavaScript, GitHub, and GitHub Pages.

The website presents fictional archive-style information using a database interface inspired by a dark corporate facility system.

TARGET AUDIENCE

  • Students
  • Game and media enthusiasts
  • Web development learners
  • Visitors interested in fictional archives
